# Citing this resource

ESCC Metabolomic Evidence Atlas. Version 1.1.0. GitHub repository: https://github.com/DrTaoHuang/escc-metabolomic-evidence-atlas. Fixed release: https://github.com/DrTaoHuang/escc-metabolomic-evidence-atlas/releases/tag/v1.1.0.

Cite this fixed release when using the atlas, and cite the original reports for specific findings. Metadata for the associated paper is not provided in this resource.

The integrated-view source archive and PNG outputs belong to this same fixed resource version. Identify the graph file or record used, and retain the original report citation and source limitations. Earlier work using v1.0.0 should continue to cite that fixed version rather than attributing later graph relationships to it.
