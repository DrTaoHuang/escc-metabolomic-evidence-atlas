# Reproducible source

The complete source archive includes the accepted public evidence, reviewed relationship input, deterministic graph generator, CSV/JSON outputs, bilingual guide and PNG results. Download and extract [the version 1.1.0 source archive](https://github.com/DrTaoHuang/escc-metabolomic-evidence-atlas/releases/download/v1.1.0/ESCC_Integrated_Atlas_v1.1.0_Source.zip) before running the generator.

The code and relationship rules in this repository match that fixed archive. The complete website is provided in the separate offline archive and on GitHub Pages. Files under releases/v1.1.0 are transport parts; the GitHub release provides the assembled ZIPs and their SHA-256 checksums.
